# ImageSpace — Sources

## Related Tools
- [PixPlot (Yale DHLab)](https://github.com/yaledhlab/pix-plot) — predecessor tool this project replaces
- [openTSNE](https://github.com/pavlin-policar/openTSNE) — FFT-accelerated t-SNE used in pipeline
- [HDBSCAN](https://github.com/scikit-learn-contrib/hdbscan) — density-based clustering
- [CLIP (OpenAI)](https://github.com/openai/CLIP) — ViT-B/32 image embeddings
- [Xenova/clip-vit-base-patch32](https://huggingface.co/Xenova/clip-vit-base-patch32) — ONNX CLIP model used
- [PixiJS](https://pixijs.com/) — WebGL sprite rendering (v8)
- [pixi-viewport](https://github.com/davidfig/pixi-viewport) — pan/zoom/pinch viewport
- [Rosé Pine Dawn](https://rosepinetheme.com/) — color palette used for UI

## Dataset
- WikiArt — 49,585 art images used for development and benchmarking
  - 1,092 unique artists, 27 styles, 47,121 unique titles
  - Processed: 49 WebP atlas textures (128px), 19 HDBSCAN clusters

## Publication
- "ImageSpace: A Modern Approach to Image Collection Visualization"
  *Computational Approaches to Art*, special issue of *Computational Humanities Research*
